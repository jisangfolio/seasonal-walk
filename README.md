# 계절길

서울 어디서나 출발지와 도착지를 고르면, 서울시 가로수 데이터와 건물 그림자로 계절마다 다른 걷기 경로를 골라 주는 실험용 웹앱이에요.

- 봄: 벚꽃길 · 이팝꽃길 · 봄꽃길
- 여름: 그늘길 (오늘 날짜 또는 한여름 7월 20일, 출근·점심·퇴근 시각)
- 가을: 단풍길 · 은행 냄새 피하기
- 겨울: 볕길 (오늘 날짜 또는 한겨울 1월 15일, 하루 볕 2시간 미만 응달 표시)
- 걷기 옵션: 계단 피하기 · 큰길 피하기

역 이름·장소를 검색하거나 지도를 눌러 두 곳을 고르면 돼요(직선 3.5km 안). 서버나 API 키는 필요 없고, 계산은 모두 브라우저 안에서 해요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면과 스타일 |
| `app.js` | 지도(타일·가로수·경로) 그리기, 검색, 날씨, 결과 카드 |
| `engine.js` | 경로·나무 집계·해 위치·그림자 계산 (화면과 무관한 순수 계산) |
| `osm.js` | 길·건물 격자 파일 읽기와 OpenStreetMap(Overpass) 예비 조회 |
| `data/seoul.js` | 지하철역 목록, 서울 경계, 격자 정보 |
| `data/ways/*.js` | 서울 전체 걸을 수 있는 길(OpenStreetMap), 4~5km 격자 |
| `data/blds/*.js` | 서울 전체 건물 바닥 모양과 높이(국토교통부 GIS건물통합정보), 4~5km 격자 |
| `data/trees/*.js` | 서울시 가로수 28만 7천여 그루, 4~5km 격자 |
| `tools/build-ways.js`, `.github/workflows/refresh-osm.yml` | 길 격자를 OpenStreetMap에서 다시 만드는 스크립트와 매달 도는 GitHub Actions |

## 동작 방식

1. 출발·도착을 잇는 띠 모양 범위에 걸치는 격자 파일(길·가로수, 여름·겨울은 건물까지)만 읽어 바로 계산해요.
2. 격자 파일이 없거나 못 읽으면 [Overpass API](https://overpass-api.de)에서 그때그때 받아요.
3. 처음 열 때 오늘 서울 날씨([Open-Meteo](https://open-meteo.com))를 보고 더우면 그늘길, 눈이 왔거나 영하로 추우면 볕길을 먼저 골라 둬요. 그 밖에는 날짜에 맞는 계절 모드예요.
4. 지도 바탕은 OpenStreetMap 표준 타일이에요(가로수와 경로가 잘 보이게 색을 눌러 그려요). 장소 검색은 [Nominatim](https://nominatim.org)을 써요.

## 계산 방법

- 나무와 길: 나무마다 25m 안 가장 가까운 보행 구간(8m 안이면 그 구간들 모두)에 붙여요. 카드의 그루 수는 경로 선에서 15m 안 가로수예요.
- 꽃길·단풍길: `구간 길이 × max(바닥값, 1 − K × 나무 밀도)`, 단풍길은 은행 암나무 한 그루마다 60m를 더해요.
- 은행 냄새 피하기: `구간 길이 + P × 은행 암나무 수`. 암나무 표시는 자치구마다 달라서 없는 곳도 있어요.
- 그늘길: 건물 바닥을 해 반대쪽으로 높이만큼 늘린 그림자와 가로수 수관 그림자를 격자로 그려, 3m 간격 점마다 그늘 여부를 봐요. 차도는 양쪽 보도 중 그늘진 쪽을 걷는다고 봐요. 오늘 날짜는 4~10월(잎이 있을 때)에만 써요.
- 볕길: 9~16시 정시 8번의 그림자로 하루 볕 시간을 세고, 2시간 미만을 응달로 봐요. 겨울엔 상록수 그림자만 넣어요. 오늘 날짜는 11~3월에만 써요.
- 건물 높이: 건축물대장의 높이(m)를 쓰고, 없으면 지상층수 × 3.3m, 둘 다 없으면 바닥 면적으로 추정해요. 서울 건물의 약 78%가 실제 높이·층수를 가지고 있어요.
- 걷기 옵션: 계단 구간은 40배, 간선도로 옆은 1.6배, 4차로 이상 길은 1.3배로 쳐서 경로를 찾아요. 최단 경로도 같은 기준이에요.
- 가중치를 바꿔 가며 후보 경로를 만들고, 우회 한도 안에서 가장 효과가 큰 후보의 90% 이상을 내는 경로 중 가장 짧은 것을 골라요.
- 출발·도착 맞추기: 고른 곳 둘레 120m 안 보행로 지점 가운데 `경로 길이 + 3 × 떨어진 거리`가 가장 작은 곳에 붙여요. 역 좌표가 하천·철길·큰길 건너편 길에 붙어 크게 돌아가는 일을 줄여요.

## 길 지도 갱신

`.github/workflows/refresh-osm.yml`이 매달 2일 새벽에 `tools/build-ways.js`를 돌려 `data/ways`를 OpenStreetMap 최신 상태로 다시 만들고 올려요. 저장소의 **Actions** 탭에서 「서울 길 지도 갱신」 → **Run workflow**로 바로 돌릴 수도 있어요. 칸마다 길 수가 이전보다 30% 넘게 줄면 서버 오류로 보고 그 칸은 바꾸지 않아요. 서버가 응답하지 않은 칸도 이전 파일을 그대로 두고, 그런 칸이 있으면 받은 칸만 올린 뒤 실행 결과를 실패로 표시해요(다음 달에 다시 받아요).

건물(`data/blds`)은 브이월드 로그인이 필요한 파일에서 만들기 때문에 자동 갱신하지 않아요.

## 데이터와 라이선스

- 가로수: 서울특별시 「서울시 가로수 위치 정보」(2026년 9월 30일 기준), [서울 열린데이터광장](https://data.seoul.go.kr/dataList/OA-23040/F/1/datasetView.do). 공공누리 제4유형(출처표시·상업적 이용금지·변경금지). 위도·경도·수종·노선 값은 바꾸지 않고 담았어요.
- 건물: 국토교통부 「GIS건물통합정보」(서울, 2026년 9월 9일 기준), [브이월드](https://www.vworld.kr). 공공누리 제1유형(출처표시).
- 도로·역·지도 타일: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright).
- 날씨: [Open-Meteo](https://open-meteo.com) (CC BY 4.0).
- 벚꽃 개화일: 기상청 보도자료(2026년 3월 29일). 단풍 시기: 웨더아이 2026 단풍 예상(2026년 9월 4일).

가로수 데이터 조건 때문에 이 프로젝트는 **비상업적 용도로만** 쓸 수 있어요. OpenStreetMap 공개 서버(Overpass, 타일, Nominatim)와 Open-Meteo는 가벼운 개인 사용을 전제로 하니, 사용자가 많아지면 자체 서버나 유료 서비스로 바꿔야 해요.

## 한계

경사, 가게 차양·아케이드, 실제 눈과 제설, 공원 안 나무(가로수 데이터에 없음), 지하보도는 반영하지 않아요. OpenStreetMap에 없는 길은 계산에 들어가지 않아요. 지도 파일은 만든 날 기준이라 그 뒤에 바뀐 길은 다음 갱신 때 반영돼요.
