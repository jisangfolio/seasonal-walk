# 계절길

서울시 가로수 데이터와 건물 그림자로 계절마다 다른 걷기 경로를 골라 주는 실험용 웹앱이에요.

- 봄: 벚꽃길 · 이팝꽃길 · 봄꽃길
- 여름: 그늘길 (출근 08:30 · 점심 13:00 · 퇴근 18:30, 시각 조절)
- 가을: 단풍길 · 은행 냄새 피하기
- 겨울: 볕길 (하루 볕 2시간 미만 응달 구간 표시)

지역은 **종로·광화문**과 **여의도** 두 곳이에요. 지도를 눌러 출발지와 도착지를 정하면 브라우저 안에서 바로 계산해요. 서버나 API 키는 필요 없어요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면과 스타일 |
| `app.js` | 지도 그리기, 입력, 결과 카드 |
| `engine.js` | 경로·나무 집계·해 위치·그림자 계산 (화면과 무관한 순수 계산) |
| `data/*.js` | 지역 데이터 (gzip + base64) |

로컬에서 보려면 `index.html`을 브라우저로 열면 돼요. 압축 해제에 `DecompressionStream`을 쓰므로 최신 브라우저가 필요해요.

## 계산 방법

- 나무와 길: 나무마다 25m 안 가장 가까운 보행 구간(8m 안이면 그 구간들 모두)에 붙여요. 카드의 그루 수는 경로 선에서 15m 안 가로수예요.
- 꽃길·단풍길: `구간 길이 × max(바닥값, 1 − K × 나무 밀도)`, 단풍길은 은행 암나무 한 그루마다 60m를 더해요.
- 은행 냄새 피하기: `구간 길이 + P × 은행 암나무 수`
- 그늘길: 건물 바닥을 해 반대쪽으로 높이만큼 늘린 그림자와 가로수 수관 그림자를 1.5m 격자로 그려, 3m 간격 점마다 그늘 여부를 봐요. 차도는 양쪽 보도 중 그늘진 쪽을 걷는다고 봐요.
- 볕길: 1월 15일 9~16시 정시 8번의 그림자로 하루 볕 시간을 세고, 2시간 미만을 응달로 봐요. 겨울엔 상록수 그림자만 넣어요.
- 가중치를 바꿔 가며 후보 경로를 만들고, 우회 한도 안에서 가장 효과가 큰 후보의 90% 이상을 내는 경로 중 가장 짧은 것을 골라요.

## 데이터와 라이선스

- 가로수: 서울특별시 「서울시 가로수 위치 정보」(2026년 9월 30일 기준), [서울 열린데이터광장](https://data.seoul.go.kr/dataList/OA-23040/F/1/datasetView.do). 공공누리 제4유형(출처표시·상업적 이용금지·변경금지). 위도·경도·수종·노선 값은 바꾸지 않고 담았어요.
- 도로·건물·공원·역: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright) (2026년 10월 6일 기준).
- 벚꽃 개화일: 기상청 보도자료(2026년 3월 29일).

가로수 데이터 조건 때문에 이 프로젝트는 **비상업적 용도로만** 쓸 수 있어요.

## 한계

경사, 가게 차양·아케이드, 실제 눈과 제설, 공원 안 나무(가로수 데이터에 없음), 지하보도는 반영하지 않아요. 건물 높이는 OpenStreetMap 높이·층수를 쓰고 없으면 바닥 면적으로 추정해요. 여의도 데이터에는 은행 암나무 표시가 없어요.
